# Number Sense Tutor — Privacy Notice

**Last updated:** September 28, 2026
**Contact:** Edgar H. — Edgar.h@leadaz.org

Number Sense Tutor is a math practice tool built for use at LeadAZ. This notice explains, in plain language, what information the tool collects, why, where it's stored, and who can see it.

## What we collect

When a student uses Number Sense Tutor, we collect:

- **The name the student types in** (there are no student accounts, logins, or passwords — just a name field)
- **Practice activity**: which problems were shown, whether each answer was correct, how long each answer took, and which practice mode/operation was used
- **Timed test results**: score, total time, and which specific problems were missed

We do **not** collect:

- Email addresses, birthdates, or any other personal identifiers beyond the name typed in
- Location data, device identifiers, or browsing activity outside this tool
- Anything used for advertising, marketing, or building a profile of the student beyond tracking their math practice

## Why we collect it

Solely to help teachers see how a student is progressing — which operations they've practiced, how accurate they are, how long problems take them, and specifically which types of problems they're missing, so instruction can be targeted to what they actually need help with.

## Where it's stored

- A copy is saved on the student's own device (in the browser's local storage), so practice works even without an internet connection.
- A copy also syncs to a Google Sheet, accessible only to staff with permission to view it, so a teacher can see a student's progress regardless of which device they used.

## Who can see it

Only school staff with access to the Teacher Dashboard or the underlying Google Sheet. Data is never sold, shared with advertisers, or used for any purpose outside supporting this student's math instruction.

## How long we keep it, and how to request deletion

Practice and test history is kept for as long as it's useful for tracking a student's progress (for example, across a school year). A parent, guardian, or staff member can request that a specific student's data be deleted at any time by contacting Edgar H. at Edgar.h@leadaz.org.

## Changes to this notice

If how this tool collects or uses data changes in a meaningful way, this notice will be updated and the change will be communicated before it takes effect.
